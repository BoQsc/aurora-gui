# Aurora Music

A small, self-contained software instrument and sequencer written in D.
It **synthesizes** piano, guitar, bass and drums from first principles — no
sampled audio, no external synth, no downloaded assets — and renders a score to
a stereo 16-bit WAV file.

Because every sound is generated by the code in this package, the whole thing
is original and is licensed **0BSD** (see `LICENSE`). Nothing here depends on
third-party samples, so no CC0 sample attribution is required. If sampled
instruments are added later, those samples should be CC0 and noted here.

## Build

```bat
dmd -i -O -release -of=build\aurora-music.exe source\app.d
```

or with DUB:

```bat
dub build --build=release
```

## Run

```bat
aurora-music demo out.wav        # render the built-in demo song
aurora-music render song.amusic out.wav   # render a score file
aurora-music play song.amusic    # render then play (or: play demo)
aurora-music selftest            # synthesize test notes and verify tuning
aurora-music                     # render the demo to aurora-music-demo.wav
```

## Instruments

- **Piano** — additive synthesis: inharmonic partials, per-partial decay,
  velocity-dependent brightness, a short hammer transient and stereophonic
  spreading of the partials.
- **Guitar / nylon / bass** — Karplus-Strong physically modelled plucked string
  with pick-position shaping, a body-resonance EQ and fractional-delay tuning.
- **Drums** — synthesized kick, snare, closed/open hi-hat, clap, tom and crash
  (pitch-swept sines, filtered noise and metallic square clusters).

A stereo Schroeder reverb is applied as a send bus and the master is
RMS-normalized with a peak safety limiter.

## Real instruments (sample bank)

When a DLS instrument bank is available, the synthesis voices are replaced by
**real recorded samples** (multisampled across the keyboard, looped and
pitch-resampled):

- **Windows:** the General MIDI bank at `C:\Windows\System32\drivers\gm.dls`
  is loaded automatically — steel guitar = program 25, nylon guitar = 24,
  piano = 0, bass = 32, drums = the Standard kit.
- **Any platform:** pass `--dls path\to\bank.dls`.
- **Force synthesis:** pass `--synth`.

The DLS reader and sampler are pure D and portable; only the default bank path
is platform-specific. If no bank is found, the built-in synthesis voices are used.

## Score format (`.amusic`)

```
# comments start with '#'
tempo 90
tail 3.0            # seconds of reverb tail after the last note

track Guitar inst=guitar gain=-4 pan=-0.3 rev=0.45
  A2 0.0 0.85 0.95     # <pitch> <beat> <velocity> <duration-in-beats>
  C4 0.5 0.80 0.95
  E4 1.0 0.80 0.95

track Drums inst=drums gain=-3 pan=0 rev=0.2
  kick 0.0 0.95        # <drum> <beat> <velocity>
  snare 1.0 0.9
  hat 0.5 0.7
```

Pitches are scientific note names (`C4`, `F#3`, `Bb2`); middle C is `C4`.
Drum names: `kick`, `snare`, `hat`, `ohat`, `clap`, `tom`, `crash`.
Instrument names: `piano`, `guitar`, `nylon`, `bass`, `drums`.
