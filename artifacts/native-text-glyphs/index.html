Consolas 17px numerals: stem-distance fix

20 October 2026 · refined D only · Windows grayscale reference

C remains the default. The reported Courier New regressions are removed: no monochrome or RGB case is worse than reviewed D. Consolas 17px isolated-numeral error falls 88.1%, with no numeral/phase regression. Courier's isolated numeral shapes remain an open gap. Exact native parity is unfinished.

Compare Consolas 17px: before / after · Live Pad++: C / updated refined D, 120 DPI · Implementation and limits

What was wrong

Unrounded horizontal MIRP kept a CVT distance even when it differed too far from the outline. This distorted numeral stems, especially 1, 2, 5 and 8. Refined D now applies the existing horizontal cut-in in that case too. The fix uses no family-name or size-specific tuning. Vertical behavior, gamma, metrics, layout and C/D pixels are unchanged.

Generated-font native probes independently confirm the horizontal behavior with symmetric and asymmetric smoothing; vertical controls remain unchanged. Signed instruction tests cover boundaries and compatibility opt-outs. Microsoft's horizontal hinting compatibility context.
