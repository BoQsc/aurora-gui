AURORA WEB DOM FEATURES - IMPLEMENTED & VERIFIED
=================================================

Implemented in:
  - aurora-web/source/auroraweb/dombind.d
  - aurora-web/source/auroraweb/dom.d

Features added (dombind.d):
  1. Element traversal/query:
     - element.closest("selector")
     - element.matches("selector")
     - element.contains(other)
     - element.getElementsByTagName("tag")
     - element.getElementsByClassName(".x")
     - document.getElementsByTagName("tag")
     - document.getElementsByClassName(".x")
     - plus sibling/traversal getters: previousSibling, nextSibling,
       firstElementChild, lastElementChild (via __get_* routing).
  2. dataset: element.dataset.foo reads data-foo, element.dataset.foo="x"
     writes data-foo. Cached per-element object with __setHandler write-through,
     camelCase <-> kebab-case conversion, refreshed on each access.
  3. Mutation methods:
     - insertAdjacentHTML(beforebegin|afterbegin|beforeend|afterend, html)
     - replaceWith(...nodes), remove(), before(...), after(...),
       prepend(...), append(...) — handles both elements and text strings
       (bare text preserved via parseFragmentNodes fallback).
  4. cloneNode(deep) — deep (default) or shallow clone; deep copies children
     recursively.
  5. scrollIntoView() — no-op that sets scrollIntoViewCalled attribute.
  6. Events enhancement:
     - event.stopPropagation() sets propagationStopped=true;
       fireEventChain halts bubbling when set.
     - currentTarget updated per ancestor during bubbling.
     - global Event constructor (new Event("type")) with preventDefault/
       stopPropagation; arbitrary props (key, etc.) settable by scripts.
     - dispatchEvent accepts an Event object OR a string name.
     - makeEventObject now also exposes stopPropagation/propagationStopped.

New unittest at end of dombind.d covers: closest/matches/contains,
getElementsByTagName/ClassName (element + document), dataset read+write,
insertAdjacentHTML all 4 positions, remove/after/before/append/prepend/
replaceWith, cloneNode deep+shallow, scrollIntoView, stopPropagation stops
bubbling, new Event + dispatchEvent with arbitrary key prop.

dom.d: unchanged (no edits needed; all changes in dombind.d).
